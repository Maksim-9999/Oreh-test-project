# Oreh — Nut Equipment Landing Page

> A responsive commercial landing page for a fictional nut-processing equipment brand.

## About the project

**Oreh** is an educational frontend project that demonstrates a content-rich commercial interface: responsive layout, interactive navigation, product and client sliders, and client-side form validation.

The project focuses on translating a complex business-oriented design into a clean, maintainable frontend implementation.

> This is a non-commercial demo created for educational and portfolio purposes. It is not affiliated with any real company, brand, or website. Content and visual materials are used only to demonstrate frontend skills.

## Highlights

- Responsive layout for desktop, tablet, and mobile screens
- Multi-level mobile navigation with expandable categories
- Product and client carousels powered by Swiper
- Contact form with client-side validation
- Modular JavaScript architecture
- Sass styles organized by page blocks and reusable UI elements
- Production-ready build with Vite

## Tech stack

- HTML5
- SCSS / Sass
- JavaScript (ES6+)
- Vite
- Swiper
- JustValidate

## Project structure

```text
src/
├── fonts/          # Local font files
├── img/            # Images and SVG assets
├── js/
│   ├── modules/    # Burger menu, sliders, and validation
│   └── script.js   # Application entry point
└── sass/
    ├── base/       # Variables, mixins, and base styles
    ├── blocks/     # Page sections and components
    ├── libs/       # Third-party styles
    ├── ui/         # Reusable UI elements
    └── style.scss  # Main stylesheet entry point
```
